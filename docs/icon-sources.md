# Project icon

The current icon is an original 64 × 64 pixel illustration of an open treasure chest and three reaching hands. Its shapes and flat-color shading are drawn directly in Python; no Lootr or Minecraft texture files are loaded, copied, traced, or resampled. The published PNG uses nearest-neighbor enlargement.

The reproducible drawing is in `scripts/draw_icon.py`; the native-resolution image is `docs/shared-lootr-icon-64.png`.

The previous icon used game textures and has been replaced. Lootr code licensing does not grant permission to use its separately licensed assets.
